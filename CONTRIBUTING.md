# Contributing to orbit-kit

Thanks for your interest in contributing! This document outlines the process.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a branch: `git checkout -b my-feature`
4. Make your changes
5. Run tests
6. Commit: `git commit -m "Add some feature"`
7. Push: `git push origin my-feature`
8. Open a Pull Request

## Code Style

- Follow the existing code style
- Keep functions small and focused
- Add tests for new features
- Update documentation as needed

## Reporting Issues

If you find a bug, please open an issue with:
- A clear title and description
- Steps to reproduce
- Expected vs actual behavior
- Your environment (OS, language version, etc.)
